飞机飞行模拟系统

C 语言代码填空 · 策略模式（Strategy）

一、题目说明

某软件公司拟开发一款飞机飞行模拟系统。不同类型的飞机具有不同的起飞方式和飞行方式。系统需要支持以后增加新的飞机种类，以及新的起飞或飞行行为。

开发人员决定采用策略模式。由于 C 语言不提供 Java 风格的接口、类和继承，本题使用结构体 + 函数指针来模拟可动态替换的行为策略。

飞机类型起飞方式飞行方式
直升机 Helicopter垂直起飞亚音速飞行
客机 AirPlane长距离起飞亚音速飞行
歼击机 Fighter长距离起飞超音速飞行
鹞式战斗机 Harrier垂直起飞超音速飞行

假设各策略函数输出对应方式的文字信息。所有空格均填写合法的 C 语言代码，标识符区分大小写。

参考答案

关键理解：策略模式把容易变化的行为独立出来。C 语言可以把函数地址保存到函数指针变量中，从而让同一架飞机在运行时切换飞行方式，而不必修改飞机结构体的定义。
